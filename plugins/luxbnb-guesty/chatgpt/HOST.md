# ChatGPT and Codex

Read this when the chat is in ChatGPT or Codex. Shared skills stay the same; this file is the ChatGPT UI.

## Workspace

- Use a **Project** with one folder (ChatGPT desktop) when reports must update themselves.
- A scheduled task on the web often cannot open project files or edit a Canvas. Prefer the desktop app, with the task set to that project directory, and the computer on.
- If a web scheduled task cannot reach Guesty, say so and schedule in Claude Cowork or Grok instead.
- Do not search the user's home folder for a place to unzip a kit. If this project already exists, write files into it.

## Documents

Drop statements and contracts in the project folder, not only in the chat:

- `reports/statements/`
- `reports/contracts/`
- `reports/contract.md`

## Instructions

Put a short instruction on the project: scope or groups, folder path, dashboard or Canvas link, and "Read reports/contract.md first."

## Scheduled tasks

Each task prompt must be complete without another skill: read-only in Guesty, contract path, the one file it writes, the Canvas or dashboard if any.

Pause after creating tasks:

1. Turn on whatever ChatGPT setting lets a scheduled run use the custom connector without a prompt each time, if the product has one.
2. Set faster checks to a faster model and the income check plus monthly briefing to the strongest model, if the scheduler allows it.
3. Come back to this chat and say continue.

Interactive Guesty changes still wait for a yes. Do not use a blanket allow for money or messages.

## This chat

Tell them to keep this project chat for later changes to the reports, and to pin or favorite it if the app allows.

Ask before running every check once to test.
